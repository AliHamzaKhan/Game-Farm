# Deploying the FarmQuest cloud server

The game is local-first and fully playable without this server — deploying it
only enables cloud-save backup, analytics collection, and remote config.
The image honours `$PORT` (Render / Railway / Fly inject it) and defaults to
`8000` otherwise. Required env vars:

| Var | Purpose |
| --- | ------- |
| `DATABASE_URL` | Postgres connection string (required — the API returns 500 without it) |
| `CLOUD_API_KEY` | Shared secret sent as the `X-Api-Key` header by the game client. Generate with `openssl rand -hex 32`. Unset = open API (dev only) |

## One-time database setup

Apply `schema.sql` to the Postgres instance exactly once (provider shell,
`psql`, or any SQL client):

```bash
psql "$DATABASE_URL" < schema.sql
```

## Option A — Render (recommended)

1. New → PostgreSQL → note the **Internal Database URL**.
2. New → Web Service → point at this repo/folder → Runtime: **Docker**.
3. Env vars: `DATABASE_URL` (internal URL), `CLOUD_API_KEY` (`openssl rand -hex 32`).
4. Health check path: `/health`.

## Option B — Railway

1. New project → add **Postgres** plugin → Deploy this folder as a service.
2. Service Variables: `DATABASE_URL` → reference `${{Postgres.DATABASE_URL}}`,
   plus `CLOUD_API_KEY`.

## Option C — Fly.io

```bash
fly launch            # accept the Dockerfile, skip Postgres on the app machine
fly postgres create   # or attach an existing managed Postgres
fly secrets set DATABASE_URL="postgresql://..." CLOUD_API_KEY="$(openssl rand -hex 32)"
fly deploy
```

## Option D — own VPS

```bash
docker build -t farmquest-cloud .
docker run -d --restart unless-stopped \
  -e DATABASE_URL="postgresql://user:pass@host/farmquest" \
  -e CLOUD_API_KEY="$(openssl rand -hex 32)" \
  -p 8000:8000 farmquest-cloud
```

Put it behind HTTPS (Caddy / nginx) — the Unity client should talk to it over TLS.

## Connecting the game

In the Unity client set the remote-config keys:

- `cloud_save_endpoint` = `https://your-server`
- `cloud_save_api_key` = the `CLOUD_API_KEY` value
- `cloud_user_id` = per-install random id (generated by the game)

Uploads happen on every save; on boot the client downloads only if the cloud
copy is newer (latest timestamp wins). All network failures are silent.
