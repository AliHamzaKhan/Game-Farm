# FarmQuest Cloud Server

Optional backend for FarmQuest (Phase 6, §43). **The game is local-first and fully
playable without this server** — it only adds cloud save backup/sync, analytics
collection, and remote config.

## Setup

```bash
pip install -r requirements.txt
createdb farmquest
psql farmquest < schema.sql
export DATABASE_URL=postgresql://user:pass@localhost/farmquest
export CLOUD_API_KEY=$(openssl rand -hex 32)   # required in production
uvicorn main:app --host 0.0.0.0 --port 8000
```

## Connecting the game

In the Unity client, set remote-config keys (or `BalanceConfig` defaults):

- `cloud_save_endpoint` = `https://your-server`
- `cloud_save_api_key` = the `CLOUD_API_KEY` value
- `cloud_user_id` = a per-install random id (generated by the game)

The client uploads on every save and, on boot, downloads only if the cloud copy
is newer (latest timestamp wins). All failures are silent — the game never
blocks on the network.

## Privacy

Analytics payloads are gameplay facts only (event name, level, counters).
The client never sends names, emails, device IDs, or advertising identifiers.
See `../unity-project/CHILD_SAFETY_AUDIT.md`.
